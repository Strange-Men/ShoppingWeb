## 性能目标的解释

v0.3 本地素材验证于 2026-11-05 实际执行：10 母版、35 派生 WebP 解码和尺寸检查、36 次本地 HTTP 200；35 图最大单文件 284,548B。首页正文去重最大回退图合计约 1.12 MB，CSS 30,740B、自托管 woff2 字体 95,436B。浏览器检查使用响应式选图、声明宽高与 lazy loading；这些资源上限不是首次加载网络记录、LCP 或海外验收结果。17 HTML、723 个本地链接／资源通过。正式门槛只因无正式域名、无已审核真实案例按预期拒绝。详见最新 QA；下方 11 月 3 日结果保留历史含义。

参考 [Web Vitals](https://web.dev/articles/vitals)，长期目标以真实访问第 75 百分位 LCP ≤2.5 秒、INP ≤200 毫秒、CLS ≤0.1 为参考。新网站没有足够真实流量时不能声称通过现场指标。上线前用可复现的手机实验室测试评估，INP 不由一次 Lighthouse 总分替代；预览空图片结果不代表正式图片结果。

## P1 本地验证（2026-11-03）

Node 24.22.1、pnpm 11.25.0、Windows、Codex in-app browser（版本接口未暴露），静态构建预览 http://127.0.0.1:4321/en/。360／390×844、768／1440×1000 CSS px，均为模拟视口，不是真实移动设备。

实际通过：frozen-lockfile 安装；Astro 0 错误／0 警告／0 提示；28 图片槽与 8 个 preview 记录的内容检查；咨询编码及非法链接断言；17 HTML、527 个本地链接／资源与 metadata 检查；16 个页面 200 和 5 个预期 404；28 次页面宽度测量、30 次四档交互断言；另有手机 Tab 焦点循环记录。脚本将内联 JS 计入预算，每页 878B gzip。

预期拒绝项已实际检查：正式资料门槛返回非零；内存注入的缺失图片路径导致检查失败；把 preview 案例误标 published 会因未审核、缺图、缺参数及占位文案而失败。注入仅发生在独立 Node 进程中，没有修改内容文件。未向第三方发送消息。

生成 HTML 已包含核心正文、案例链接和 noscript 图片回退；原生 details 不依赖应用脚本。本轮没有浏览器“禁用 JavaScript”设置能力，未将 HTML 结构检查写成完整无 JS 浏览器验收。最终素材性能、真实账号、海外 DNS／TLS、真实设备、正式 SEO、翻译与 RTL 完整页面均保留待验。详细环境与截图见 [qa/README](qa/README.md)。
