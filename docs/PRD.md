# 定制雕塑海外官网产品需求

版本 v0.1；2026-11-03；状态：可评审草案；业务负责人：业主；文档维护：开发执行方。

## 项目目标

为楠轩雕塑建立面向欧美、中亚、印度及港澳台客户的定制雕塑官网，展示玻璃钢与不锈钢的定制能力和案例，引导客户通过 WhatsApp 和邮箱咨询。英文品牌名未定，域名与服务器尚未购买。参考站为 https://tongmeisculpture.com/，视觉尽量贴近其布局、配色与交互。品牌、图片和企业信息换为业主自有资料。

先完成英文页面和素材版式，再推进繁体中文与阿拉伯语；没有管理后台，固定内容通过仓库维护后重新构建发布。源码和文档存于 https://github.com/Strange-Men/ShoppingWeb 。技术选择详见[技术方案](ARCHITECTURE.md)，证据详见[参考站分析](research/REFERENCE_ANALYSIS.md)。

## 已确认业务约束

- 产品为定制类玻璃钢与不锈钢雕塑，两种材料分类；不是现货交易。
- 业主确认服务包含来图制作、设计／3D 建模、打样、生产、包装运输与安装指导；具体费用、范围边界与交付周期尚未提供。
- 不需要管理后台；图片、版式、文字确定后预计少改。
- 第一版英文，预留三语切换卡片；繁中和阿语后续上线。
- WhatsApp 与邮箱为主要咨询入口，Facebook 与 Instagram 为辅助入口；账号后补。
- 第一版不做网站留言表单。
- 部署腾讯云，外国客户可通过域名公开访问；需要 SEO。
- 缺失的企业信息及图片先占位，不采用同行的品牌、客户评价或联系资料。

## 目标用户与路径

采购方、景观设计方、商业空间或项目客户先了解材料与定制能力，再查看案例，最后携带案例链接、参考图、尺寸、数量与项目所在地联系业务方。客户身份是设计假设，尚未通过真实访谈验证；地区分布为业主确认。

路径：搜索或分享链接 → 首页或材料页 → 定制案例详情 → WhatsApp／邮件沟通。访客无需注册，网站不接收文件、不存储询盘、不处理订单。转化指标先定义为咨询入口点击；是否安装分析工具待决定，点击不等于真实有效询盘。

定制流程模块按业主确认的能力规划：需求／来图沟通 → 设计与 3D 建模 → 打样确认 → 制作 → 包装运输 → 安装指导。实际项目是否需要每一步、收费、范围和时限以沟通约定为准，网页不预设免费打样、全球包邮或到场安装。

## 分阶段范围

| 阶段 | 交付 | 完成边界 |
| --- | --- | --- |
| P0 前期 | PRD、参考调研、技术与治理文档 | 事实与假设可追溯；本次范围 |
| P1 英文预览 | 页面、两类材料、案例模板、语言卡片、占位素材 | 可演示布局与交互；预览 noindex |
| P2 英文正式发布 | 自有资料替换、域名与 HTTPS、SEO、咨询入口、海外检查 | 真实联系方式和必要内容齐全；占位不公开收录 |
| P3 三语 | 繁中与阿语内容、等价页切换、RTL、语言 SEO | 内容校对和逐页验收后启用对应语言 |

页面数量由真实案例数决定。可先预留每类 4 个案例插槽共 8 个，仅为版式容量假设，不是业主承诺有 8 个真实案例。

## 功能需求

| ID | 优先级／阶段 | 需求与可观察结果 |
| --- | --- | --- |
| FR-001 | P0／P1 | 首页包含品牌导航、主视觉、定制介绍、精选案例、两类材料、工艺优势、定制流程与咨询区；模块顺序参考同行，业务内容围绕定制 |
| FR-002 | P0／P1 | 材料入口固定为玻璃钢 FRP 和不锈钢；各自有可直接打开的独立列表 URL；卡片可进入案例详情 |
| FR-003 | P0／P1 | 案例详情支持图片组、材料、尺寸可定制、表面工艺、应用场景、定制说明与咨询入口；无虚构技术参数、库存、价格或交期 |
| FR-004 | P0／P1 | 关于页展示真实企业资料、制作能力与流程；联系页展示有效联系方式；缺失资料在预览中占位 |
| FR-005 | P0／P1 | 桌面和手机均可打开三语卡片，显示 English、繁體中文、العربية；英文可用，未发布语言非可点击链接并明确尚未上线；支持键盘、关闭及焦点恢复 |
| FR-006 | P0／P2 | 有效 WhatsApp 链接含编码后的案例名称和正式 URL；邮件链接含主题和正文；点击打开对应应用或网页，不宣称消息已发出；无账号不生成虚假链接 |
| FR-007 | P1／P2 | Facebook 与 Instagram 仅在已配置有效账号时展示可用链接；外部新窗口使用合适的安全属性；无需嵌入社交 SDK |
| FR-008 | P0／P1 | 导航、菜单、卡片、图片浏览及咨询按钮在桌面和手机可用；核心文字、案例与链接无需客户端 JS 即可阅读或访问 |
| FR-009 | P0／P1-P3 | 图片、内容、联系信息集中配置；按稳定案例 ID 关联多语言；支持草稿与已发布状态；一次替换自有图片后无需修改各页面模板 |
| FR-010 | P0／P3 | 三语等价页可互相跳转并保持案例身份；繁中使用繁体内容，阿语设置 RTL；不生成大量英文重复的伪翻译页 |
| FR-011 | P1／后续 | 预留文章数据和模板；无真实文章不发布空博客页、导航入口或虚构文章；博客内容上线需补充需求与验收 |
| FR-012 | P0／P2 | 域名公开访问、HTTPS 正常、路径直接刷新可用、错误路径返回真实 404；源码与部署说明归档到指定 GitHub 仓库 |

P0 表示必需，P1 表示条件性或后续增强，不表示项目阶段。正式验收以[验收矩阵](ACCEPTANCE.md)为准。

## 非功能需求

| ID | 范围 | 约束 |
| --- | --- | --- |
| NFR-001 | SEO | 每个已发布页面静态 HTML 有独立标题、描述、自引用 canonical、一个明确主标题和可抓取内链；站点地图仅含可索引正式页 |
| NFR-002 | 性能 | 优化图片、指定尺寸、首屏主图不懒加载、非首屏懒加载；预设页面 JS 压缩传输预算 50KB、首页资源总量目标 2MB，最终素材后复测；现场指标与实验室结果分开记录 |
| NFR-003 | 响应式与可访问 | 以 360、390、768、1440px 验证无横向溢出，键盘可操作，焦点可见，图片有语义化替代文本；实际浏览器版本与设备写入记录 |
| NFR-004 | 内容真实性 | 不编造厂龄、认证、客户评价、订单、案例归属、耐候年限或交期；正式版本中无未说明的占位图片和联系资料 |
| NFR-005 | 运维 | 静态产物可复现构建，留存上一个可用版本，TLS 自动续期方案与续费提醒可交接；凭据不进入仓库 |
| NFR-006 | 海外可用 | 域名 DNS、TLS、HTML 和必要资源从目标区域可访问；社交平台不可达时仍可阅读网站并看到邮箱；不承诺所有运营商同样延迟 |

## 不在第一版范围

管理后台、登录注册、购物车、在线支付、库存、报价计算、留言及邮件发送接口、在线文件上传、CRM、在线翻译订阅服务、俄语和印度本地语言。阿语保留是用户明确要求，不等同于中亚或印度主要语言；若需俄语等，另行扩展。

## 依赖与发布门槛

域名与服务器采购、品牌名、真实图片、真实案例文字、至少一个有效咨询渠道、上线内容授权与最终文字确认，是正式发布依赖。英文占位版可以先做，不因资料未齐停止模板开发。繁中／阿语的发布依赖对应内容与人工校对；不把未回应的开放问题当作同意。

阶段排期在案例数量、素材完整度和视觉预览后估算。当前不承诺固定交付日期，也不承诺搜索排名。
