## 阅读顺序

业主先读 PRD、决策、素材清单与部署成本；开发先读参考站分析、技术方案、语言与 SEO、验收矩阵；后续贡献者遵循治理规范。

## 状态用词

“业主已确认”只用于本次及此前对话中明确的业务要求。“建议”是可调整的技术判断。“待补充”不等于同意默认值。“待执行”不等于检查通过。无业务资料时可以推进占位版，不能据此宣称已可对外正式获客。
